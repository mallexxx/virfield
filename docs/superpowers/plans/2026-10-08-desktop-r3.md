# R3 Desktop Access to VM Leases — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open a ready VM lease's desktop (Tart or HTPC macOS VM) in Screen Sharing.app through a private, lease-bound loopback tunnel, with `virfield desktop`, the Web Console and MCP.

**Architecture:** Lease preparation enables guest macOS Screen Sharing. Lease tunnels become per service (`ssh`, `desktop`); a desktop tunnel dials through a runtime `ServiceDialer` (Tart: lease IP:5900 on the host-only network; HTPC VM: the guest's 5900 forwarded by passt and published on the node loopback, reached over node SSH) and returns `vnc://admin:<lease password>@127.0.0.1:<port>`.

**Tech Stack:** Go, POSIX sh guest/node scripts, dockurr/macos (passt `USER_PORTS`, `VNC_PORT`), macOS `launchctl`, Screen Sharing (Apple RFB 003.889).

**Spec:** `docs/superpowers/specs/2026-10-08-desktop-r3-design.md`

func (e *Manager) LeasePassword(l domain.Lease) (string, error) {
